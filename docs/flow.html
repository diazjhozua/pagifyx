End-to-end flow, code level

One brochure goes through five phases. Each phase starts with one browser request and ends with a redirect. Every step below names the function that runs it and where it lives. Use the lane colour to see which layer does the work.

0 Startup once per process create_app()
1 Read website POST /sessions read_website()
2 Plan the brochure POST /sessions/{id}/fold choose_fold()
3 Revise POST /sessions/{id}/revise revise()
4 Approve and build POST /sessions/{id}/approve approve()

Phases 2 and 3 can repeat. Revise as many times as needed, then approve. Phase 4 can run again after a revision, which clears the old download link.

Lane legend

Each step is tagged with the layer that does the work.

Browser the user's browser, forms and redirects Route web/routes.py, validates input, calls the service Service workflow/service.py, runs the workflow and commits state Collaborator scraper, assets, theme, fonts, brand Model llm/client.py and llm/prompts.py, the LLM call Domain folds, images, docx builder, the output file State workflow/session.py, in memory
